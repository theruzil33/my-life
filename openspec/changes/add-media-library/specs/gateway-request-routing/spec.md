## MODIFIED Requirements

### Requirement: Маршрутизация по префиксу URL к настроенному сервису

Gateway SHALL перенаправлять входящий запрос к backend-сервису, сопоставленному с префиксом пути запроса согласно статической конфигурации маршрутов, сохраняя метод запроса, тело и заголовки, не зарезервированные gateway. Конфигурация маршрутов SHALL включать префикс `/finances`, сопоставленный с сервисом финансов, и префикс `/media`, сопоставленный с сервисом медиатеки.

#### Scenario: Запрос к известному префиксу маршрутизируется в нужный сервис

- **WHEN** входящий запрос имеет путь с префиксом, сопоставленным в конфигурации с конкретным backend-сервисом
- **THEN** gateway перенаправляет запрос на этот сервис с тем же методом и телом и возвращает клиенту ответ сервиса без изменений содержимого

#### Scenario: Ответ сервиса возвращается клиенту без искажений

- **WHEN** backend-сервис отвечает на перенаправленный запрос с определённым статус-кодом и телом
- **THEN** gateway возвращает клиенту тот же статус-код и то же тело ответа

#### Scenario: Запрос к префиксу /finances маршрутизируется в сервис финансов

- **WHEN** входящий аутентифицированный запрос имеет путь с префиксом `/finances`
- **THEN** gateway перенаправляет запрос в сервис финансов с сохранением метода, тела и идентификатора аутентифицированного пользователя и возвращает клиенту ответ сервиса без изменений содержимого

#### Scenario: Запрос к префиксу /media маршрутизируется в сервис медиатеки

- **WHEN** входящий аутентифицированный запрос имеет путь с префиксом `/media`
- **THEN** gateway перенаправляет запрос в сервис медиатеки с сохранением метода, тела и идентификатора аутентифицированного пользователя и возвращает клиенту ответ сервиса без изменений содержимого

#### Scenario: Запрос к /media без аутентификации отклоняется

- **WHEN** входящий запрос имеет путь с префиксом `/media`, но не содержит действующего JWT access-токена
- **THEN** gateway отвечает ошибкой аутентификации и не перенаправляет запрос в сервис медиатеки
