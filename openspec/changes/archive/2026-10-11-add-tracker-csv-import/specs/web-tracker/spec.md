## ADDED Requirements

### Requirement: Кнопка импорта и модальное окно загрузки CSV-файла

В шапке страницы трекера рядом с заголовком SHALL отображаться кнопка импорта CSV-файла. Нажатие кнопки импорта SHALL открывать модальное окно импорта, а не встроенную форму на вкладках. Модальное окно SHALL содержать выбор месяца и года и выбор файла. По умолчанию SHALL быть выбран текущий календарный месяц. Модальное окно SHALL закрываться по отмене без отправки запроса. Веб-клиент MUST NOT отправлять запрос импорта, если файл не выбран, и SHALL показывать понятное сообщение о необходимости выбрать файл. При отправке веб-клиент SHALL передавать access-токен в заголовке авторизации и CSRF-токен, отправляя файл вместе с выбранным месяцем и годом. Пока запрос импорта выполняется, веб-клиент SHALL показывать признак загрузки и MUST NOT позволять повторно инициировать импорт.

#### Scenario: Кнопка импорта в шапке страницы трекера

- **WHEN** аутентифицированный пользователь открывает страницу трекера
- **THEN** веб-клиент показывает в шапке кнопку импорта

#### Scenario: Нажатие кнопки импорта открывает модальное окно

- **WHEN** пользователь нажимает кнопку импорта
- **THEN** веб-клиент открывает модальное окно импорта с выбором месяца, года и файла

#### Scenario: Импорт не показан встроенной формой на вкладках

- **WHEN** аутентифицированный пользователь открывает вкладки «Привычки», «Задачи» или «Статистика»
- **THEN** веб-клиент не показывает форму импорта внутри содержимого вкладки

#### Scenario: Месяц по умолчанию

- **WHEN** пользователь открывает модальное окно импорта
- **THEN** веб-клиент показывает выбранным текущий календарный месяц

#### Scenario: Отмена закрывает модальное окно без импорта

- **WHEN** пользователь закрывает модальное окно импорта, не отправляя файл
- **THEN** веб-клиент закрывает модальное окно и не отправляет запрос импорта

#### Scenario: Отправка без выбранного файла недоступна

- **WHEN** пользователь пытается импортировать, не выбрав файл
- **THEN** веб-клиент не отправляет запрос и показывает сообщение о необходимости выбрать файл

#### Scenario: Импорт передаёт учётные данные и CSRF-токен

- **WHEN** веб-клиент отправляет выбранный файл с месяцем и годом
- **THEN** запрос к API трекера содержит access-токен, CSRF-токен, файл, месяц и год

#### Scenario: Повторный импорт недоступен во время запроса

- **WHEN** запрос импорта ещё выполняется
- **THEN** веб-клиент не позволяет повторно инициировать импорт

### Requirement: Результат и обновление данных после импорта

При успешном импорте веб-клиент SHALL показывать сводку результата (количество созданных активностей и количество сохранённых отметок) и SHALL обновить отображаемые данные трекера, чтобы отразить импортированные активности и отметки. При ошибке импорта веб-клиент SHALL показывать понятное сообщение об ошибке. До успешного ответа API трекера веб-клиент MUST NOT показывать сводку результата как успешную.

#### Scenario: Успешный импорт показывает сводку

- **WHEN** API трекера успешно завершает импорт
- **THEN** веб-клиент показывает количество созданных активностей и количество сохранённых отметок

#### Scenario: Успешный импорт обновляет данные трекера

- **WHEN** API трекера успешно завершает импорт
- **THEN** веб-клиент перечитывает данные открытой вкладки трекера, чтобы отразить импортированные активности и отметки

#### Scenario: Ошибка импорта показывает сообщение

- **WHEN** запрос импорта завершается сетевой ошибкой или ошибкой сервера
- **THEN** веб-клиент показывает сообщение об ошибке и не показывает успешную сводку

#### Scenario: Сводка не показывается во время импорта

- **WHEN** запрос импорта ещё выполняется
- **THEN** веб-клиент показывает признак загрузки и не показывает успешную сводку
